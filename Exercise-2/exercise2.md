# Exercise 2 - CSS Box Model

## Introduction

In this exercise, you will practice using the CSS box model to create layouts and style elements.

## Instructions

### Part 1: Box Model Basics

1. Open the `exercise2.html` file in your code editor.
2. Create a `styles.css` file and link it to the `exercise2.html` file.
3. Add the following styles to the `styles.css` file:

    - Set the `box-sizing` property to `border-box` for all elements.
    - Style the `div` element with a width of `300px`, height of `200px`, background color of `#f0f0f0`, and a border of `1px solid #ccc`.
    - Add padding of `20px` to the `div` element.
    - Add margin of `10px` to the `div` element.
    - Style the `h1` element with a background color of `#333`, text color of `#fff`, padding of `10px`, and margin of `0`.
    - Style the `p` element with a background color of `#f0f0f0`, text color of `#333`, padding of `10px`, and margin of `0`.

4. Save the changes and open the `exercise2.html` file in a web browser to view the styled elements.

### Part 2: Layout Exercise

1. Create a new `div` element with a class of `container` inside the existing `div` element.
2. Add the following styles to the `container` class:

    - Set the width to `100%`.
    - Set the background color to `#f0f0f0`.
    - Add padding of `20px`.
    - Add margin of `10px`.

3. Inside the `container` div, create two `div` elements with classes `sidebar` and `content`.
4. Add the following styles to the `sidebar` class:

    - Set the width to `25%`.
    - Set the background color to `#333`.
    - Set the text color to `#fff`.
    - Add padding of `10px`.
    - Add margin of `10px`.

5. Add the following styles to the `content` class:

    - Set the width to `75%`.
    - Set the background color to `#f0f0f0`.
    - Set the text color to `#333`.
    - Add padding of `10px`.
    - Add margin of `10px`.

6. Save the changes and open the `exercise2.html` file in a web browser to view the styled layout.

### Additional

1. Experiment with different values for padding, margin, and width to see how they affect the layout.
2. Add borders to the `sidebar` and `content` divs to visually separate them.
3. Add a header with a background color and padding to the `container` div.
