Layout Measurements

  • Left Sidebar: 20% width
  • Gap after left sidebar: 2.5% (use margin-right)
  • Main Content: 55% width
  • Gap after main content: 2.5% (use margin-right)
  • Right Sidebar: 20% width
  • Total: 20% + 2.5% + 55% + 2.5% + 20% = 100%

Important Notes:
  • All containers with floated children must have the clearfix class
  • The footer must clear floats to appear below all content
  • Use box-sizing: border-box to include padding in width calculations
  • Photo cards in the main content area should also use float: left

CSS Code Structure

/* Essential clearfix */ .clearfix::after { content: ""; display: table; clear: both; } /* Header with floated elements */ .gallery-header { /* styles */ } .logo { float: left; } .main-nav { float: right; } /* Three-column layout */ .gallery-container { /* max-width, margin, etc. */ } .left-sidebar { float: left; width: 20%; margin-right: 2.5%; } .main-gallery { float: left; width: 52.5%; margin-right: 2.5%; } .right-sidebar { float: right; width: 20%; } /* Photo grid items */ .photo-card { float: left; width: 30%; margin-right: 3%; } .photo-card:nth-child(3n) { margin-right: 0; /* Remove margin on every 3rd item */ } /* Footer */ .gallery-footer { clear: both; /* Essential! */ }

Photo Grid Calculations

For 3 columns of photo cards:

  • Each card: 30% width
  • Gap between cards: 3% (use margin-right)
  • Calculation: 30% + 3% + 30% + 3% + 30% = 96% (4% margin of error is fine)
  • Every 3rd card: Remove right margin using :nth-child(3n)
  • Container must have clearfix to contain all floated cards

Pro Tip: Build your layout incrementally!
  1. Start with the header - get logo and nav floating correctly
  2. Add the three-column layout - test with placeholder content
  3. Build the photo grid - start with just 3 cards to test alignment
  4. Add the footer - make sure it clears properly
  5. Fill in all content and refine styling
