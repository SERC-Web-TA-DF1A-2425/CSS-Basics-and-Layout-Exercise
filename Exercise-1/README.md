# Exercise 1 - CSS Basics and Styling

## Overview
This exercise has been expanded to provide comprehensive coverage of CSS styling properties while keeping layout topics for Exercise 2.

## What's Included

### exercise1.md (480 lines)
A comprehensive guide covering:
- **Introduction to CSS**: What it is, why use it, syntax basics
- **Three ways to add CSS**: Internal, external, and inline styles
- **Part 1 - Guided Steps** covering:
  1. Setting up internal styles
  2. Colors (color, background-color, opacity)
  3. Typography (font-family, font-size, font-weight, font-style, line-height, letter-spacing)
  4. Text formatting (text-align, text-decoration, text-transform, text-indent)
  5. Link styling and pseudo-classes (:link, :visited, :hover, :active)
  6. Borders and border-radius
  7. Shadows (box-shadow, text-shadow)
  8. List styling (list-style-type, list-style-position)
- **Part 2 - Advanced Selectors**:
  - Class and ID selectors
  - Descendant and child selectors
  - Pseudo-classes (:first-child, :last-child, :nth-child, :hover, :focus)
  - Pseudo-elements (::before, ::after, ::first-letter, ::first-line)
- **Part 3 - External Stylesheets**: How to move from internal to external CSS
- **Part 4 - Partially Independent Tasks**: 8 practical tasks with less guidance
- **Summary**: Complete list of topics covered
- **Tips and Resources**: Best practices and helpful links

### exercise1.html (179 lines)
Enhanced HTML file providing:
- Semantic structure (header, nav, main, sections, footer)
- Multiple sections showcasing different styling opportunities
- Various elements for practicing:
  - Colors and backgrounds
  - Typography and text effects
  - Lists (ordered, unordered, custom styled)
  - Links in different states
  - Boxes with borders and shadows
  - Message types (warning, success, info)
  - Quotes and code blocks
  - Buttons and gallery items
- Clean structure ready for students to add their styles

### styles-solution.css (307 lines)
A complete reference solution demonstrating:
- All CSS concepts from the exercise
- Well-organized with comments
- Best practices for CSS structure
- Examples of all selectors and properties taught
- Can be used by instructors as a reference

## What's NOT Included (Reserved for Exercise 2)
The following layout-related topics are explicitly excluded:
- `display` property (block, inline-block, flex, grid)
- `position` property (static, relative, absolute, fixed, sticky)
- `float` and `clear`
- `width` and `height` properties
- `padding` and `margin` (box model spacing)
- `box-sizing` property
- Flexbox properties
- Grid properties
- Multi-column layout

## Pedagogical Approach
The exercise follows best practices for teaching:
1. **Explanations First**: Each concept is explained before being practiced
2. **Guided Practice**: Early tasks provide step-by-step instructions
3. **Progressive Independence**: Later tasks require more independent thinking
4. **Practical Application**: All concepts are immediately applied to HTML
5. **Visual Learning**: Students see results in browser immediately
6. **Reference Material**: Solution file available for comparison

## How Students Will Use This
1. Read through exercise1.md for instructions and explanations
2. Open exercise1.html in a code editor
3. Start with internal styles in `<style>` tags
4. Practice each CSS concept with guided steps
5. Move to external stylesheet (styles.css)
6. Complete independent tasks
7. Compare their work with styles-solution.css
