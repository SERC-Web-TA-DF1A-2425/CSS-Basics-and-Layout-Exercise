# Exercise 1 - CSS Basic Selectors

## Introduction

In this exercise, you will practice using CSS selectors to style HTML elements.

## Instructions

### Part 1: Internal Styles

1. Open the `exercise1.html` file in your code editor.
2. Inside the `<head>` element, add a `<style>` element.
3. Inside the `<style>` element, add CSS rules for the following:

    - Style the `h1` element with a font size of `24px`.
    - Style the `p` element with a font size of `16px`.
    - Style the `ul` element with a font size of `14px`.
    - Style the `li` element with a font size of `12px`.

4. Save the changes and open the `exercise1.html` file in a web browser to view the styled elements.
5. Add margins to the `<div>` element with class "box". 
6. Style the `<div>` element with class "box" with a background color of `#f0f0f0` and a border of `1px solid #ccc`.
7. Style the `<a>` element with a text decoration of `none` and a color of `#333`.

### Part 2: External Styles

1. Create a new CSS file named `styles.css`.
2. Move the CSS rules from the `<style>` element in `exercise1.html` to the `styles.css` file.
3. Link the `styles.css` file to the `exercise1.html` file using an external stylesheet link.
4. Save the changes and open the `exercise1.html` file in a web browser to view the styled elements.

### Additional

1. Add background color and padding to the `li` elements in the `ul` list.
2. Style the `h1` element with a different font family.
3. Add a hover effect to the `<a>` element.

## Summary

In this exercise, you practiced using CSS selectors to style HTML elements. You learned how to apply styles using internal and external stylesheets, as well as how to target specific elements with CSS selectors.
